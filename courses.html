1. ໂປຣແກຣມຮຽນ 1 ຕໍ່ 1 (1-on-1 Mentorship)

ຮຽນຕາມຄວາມໄວຂອງຜູ້ຮຽນ
ພື້ນຖານ - ລະດັບກາງ 1 ຕໍ່ 1 (ຢູ່ສູນ / ອອນລາຍ)

Basic Coding & Problem Solving (ພື້ນຖານການຂຽນໂປຣແກຣມ)

ປູພື້ນຖານການຂຽນໂຄ້ດສຳລັບຜູ້ເລີ່ມຕົ້ນ, ຄວາມເຂົ້າໃຈ Logic, ໂຄງສ້າງຂໍ້ມູນ, Git/GitHub, ແລະ ການຂຽນໂປຣແກຣມແກ້ໄຂບັນຫາ.

ຫົວຂໍ້ຫຼັກ:

  • ພື້ນຖານ Programming Concept & Logic
  • Git & ການຈັດການເວີຊັນຂອງໂຄ້ດ
  • Mini Project: Command-line App
ໄລຍະເວລາ: ປັບຕາມຜູ້ຮຽນ ສອບຖາມ / ຈອງຮອບຮຽນ
ລະດັບກາງ - ມືອາຊີບ 1 ຕໍ່ 1 + ກວດສອບໂຄ້ດ

Project-Based Mentorship (ສ້າງໂປຣເຈັກຈິງ)

ຮຽນຜ່ານການສ້າງໂປຣເຈັກຕົວຈິງທີ່ຕ້ອງການ ພ້ອມຄຳແນະນຳລະດັບ Architecture, Code Review ແລະ ການກຽມພ້ອມເຮັດວຽກ.

ຫົວຂໍ້ຫຼັກ:

  • ການອອກແບບ System Architecture ຄົບວົງຈອນ
  • Code Review ແບບມືອາຊີບ
  • Deploy ຂຶ້ນ Server ຈິງພ້ອມ Domain
ໂຄງການຕາມເປົ້າໝາຍຜູ້ຮຽນ ປຶກສາໂປຣເຈັກ
